# Hack Apertus rules verification — 2026-10-12

## Independently verified from first-party sources

- Event: Hack Apertus Online Hackathon, 1–16 October 2026.
- Deadline: 16 October 2026, 12:00 CEST, which is 13:00 Europe/Kyiv on that date.
- Team size: 1–5 people; solo participation is therefore supported.
- Track: 2B, Apertus Adoption — Own Project.
- Objective: a new working prototype built during the hackathon using the
  Apertus model family.
- Mandatory architecture: on-premise, air-gapped, or sovereign Swiss cloud.
- Required model family: Apertus; listed checkpoints are v1.5 8B and 70B.
- Repository: public, created from the template, with `track_2b/` preserved.
- Runtime: Docker container launched by `make run`, end to end.
- Report: `TeamName_Report.pdf`, maximum six pages excluding references.
- Demo: public video URL, maximum two minutes.
- Dataset: optional; if submitted, use the HF template, publish evaluation
  cases/responses/metadata, and include instance licences.
- Judging: purposeful AI; technical rigour; value, cost and scalability;
  sovereign deployability; implementation feasibility, each scored 0–5.
- General eligibility: registration is personal and participants must be 18+.
- Licences on submission: Apache-2.0 code/model weights, CC-BY-4.0 docs/designs,
  CDLA-Permissive-2.0 datasets unless event-specific terms override.
