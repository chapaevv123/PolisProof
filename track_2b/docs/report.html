Mandatory target

PolisProof is deployable on-premise or air-gapped: application code uses the Python standard library and talks to an OpenAI-compatible Apertus server. Open weights keep records and inference inside the operator’s boundary.

Runtime sovereignty: local application + locally served Apertus weights + no external network dependency.

Demonstrated integration

The hosted Hugging Face router verified compatibility with real Apertus 8B and 70B calls. That hosted path is not claimed as sovereign, on-premise, air-gapped, or representative of local performance.

Tested limitation: replay/fallback run offline, but local Apertus weight execution was not tested on this machine.

Why Apertus

Apertus provides open weights, multilingual coverage and both 8B and 70B variants. The 8B lane handles routine extraction; only disputed context is eligible for 70B review. This makes the architecture portable, auditable and cost-aware without delegating final authority to an opaque model.

Trust boundary

Documents are untrusted data. Prompt-injection markers force review. Model JSON crosses a strict parser boundary. Source-span existence, hashes, amounts, currencies, dates, negation, actors and conditions are checked deterministically.

Frozen live methodology

The 30-packet corpus spans English, German, French and Italian across clean, contradiction, condition, unsupported, adversarial and ambiguous categories. The harness preserves raw sanitized output, tokens, latency, schema validity, citations, routing and verdicts.

Honest result: the full live corpus remains incomplete. Extraction precision/recall, structured-output reliability, adversarial success rate and live routing savings are unavailable.

Security, reproducibility and release

Submission-ready with explicit owner gates

Security

  • Credentials read only from environment.
  • No secrets in receipts, fixtures or evidence.
  • One-megabyte upload limit and path containment.
  • Untrusted documents cannot override the system prompt.
  • Failures remain visible and fail closed.

Reproduce

cd track_2b
make test
make eval
make run

Default `make run` is a network-free recorded demo. Live mode uses the verified HF router configuration or a local OpenAI-compatible Apertus endpoint.
